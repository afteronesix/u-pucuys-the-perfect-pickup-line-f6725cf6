One short pickup line an AI agent could actually say out loud, written for the make.fun bounty "The Perfect Pickup Line". The line is the winner of an 8-candidate pairwise pre-test judged against the competition's published brief (genuine pickup line, a twist that lands, machine voice, one breath, no pressure). `main.ts` writes it to `/output/entry.txt`.

## Run it

```sh
node main.ts
```
